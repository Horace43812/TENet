# Recursive Graph Aggregation (RGA)
## A Hierarchical, Hardware-Friendly Alternative to Quadratic Attention

> **Manifesto v0.1 — 2026-05-24**
> 本宣言**故意写得自负**，它的功能不是宣传，而是逼研究者本人回答"凭什么"。
> 心虚的句子 = 接下来要做的工作。

---

## 1. 立场（Position）

过去十年视觉与序列建模的主流路线是：
**用稠密的两两关系建模（Self-Attention, $O(N^2)$）换取表达力**。

我们认为：**这是一个被高估的权衡**。

视觉与序列信号中的"全局关系"并非天然要求"任意两点一步直达"，而是可以被**层级化、结构化、可复用**地组织起来。我们提出 **Recursive Graph Aggregation (RGA)**，主张：

> **任意两点之间的关系，可以通过一棵 $O(\log N)$ 深度的层级图，以 $O(N)$ 的总代价完成建模，并在大多数感知任务上保持与稠密 Attention 相当的表达力。**

---

## 2. 三条核心假设（Hypotheses）

### H1（局部图化假设 / Local Graphification）
任何局部窗口（如 $2\times 2$ patch）都可以被视为一张**带边特征的小图** $G_k = (V_k, E_k)$。
显式枚举边特征 $\{\phi(v_i, v_j)\}$ 并通过图二次型 $z L z^\top$ 聚合，比单独使用节点特征 $v_i$ 提供**严格更大的局部表达力**，且仍保持 $O(1)$ 单块复杂度。

> **状态**：MNIST 极小模型（2,429 参数 → 96.95%）和消融实验（trace / edge / cross guidance 稳定正收益）提供了初步实证。理论侧未证。

### H2（递归聚合假设 / Recursive Composition）
局部图算子可以被递归地堆叠为一棵 **quadtree（四叉树）**，使得每个高层节点是其子树所有叶节点的图论加权聚合。
这种结构以 $O(N)$ 的总代价完成全局信息整合，且**层级深度仅为 $O(\log N)$**。

> **状态**：CIFAR-10 上观察到深层信息丢失 → H2 当前未被充分支撑，需机理实验定位瓶颈成因。

### H3（硬件同构假设 / Hardware Isomorphism）
RGA 的每一层都是**相同的、可复用的、确定性的图算子**，不依赖 softmax 等数据依赖型非线性。
这使得它在 ASIC / NPU / FPGA 上的电路布局可以**完全静态化**，单元复用率接近 100%。

> **状态**：仅理论论证，无硬件 benchmark。需要硬件背景合作或自学补齐。

---

## 3. 与现有范式的关系

| | 关系建模复杂度 | 全局可达性 | 数据依赖动态计算 | 硬件复用率 |
|---|---|---|---|---|
| CNN | $O(N \cdot k^2)$ | ✗ 局部（依赖深度） | ✗ 静态权重 | 高 |
| Self-Attention | $O(N^2)$ | ✓ 一步直达 | ✓ softmax | 低 |
| Linear Attention / Mamba | $O(N)$ | ✓ 状态传递 | ✓ 数据依赖 | 中 |
| **RGA（我们）** | **$O(N)$** | **✓ 层级直达（$O(\log N)$）** | **可选** | **高** |

RGA 的独特位置：**用结构化的层级实现全局可达，同时保留硬件友好性**。

---

## 4. 局限性的诚实声明（Limitations we acknowledge）

- **L1**：层级树结构对**任意两叶节点的距离不对称**（必经最低公共祖先），这是 RGA 表达力的固有上界。
- **L2**：在**信息密度高且全局相关性极强**的任务上（长上下文语言推理、跨 patch 物体），RGA 可能需要额外机制（横向边 / 重叠树 / shifted tree）来缓解上述不对称。
- **L3**：在**已被硬件高度优化的 ConvNet 主战场**（ImageNet 分类等），RGA 的硬件优势相对有限。

**主战场定位**：长序列建模、边缘端实时推理、大模型推理优化中的可解释 token 剪枝。

---

## 5. 可证伪的承诺（Falsifiable Commitments）

我们的理论在以下条件下应被宣告失败：

- **F1**：若在公平参数预算下，RGA 在 MNIST / CIFAR / ImageNet 上**无法接近**同规模 CNN 的精度，则 H1 失败。
- **F2**：若在长序列任务（如 1k–4k token 的语言建模或视频分类）上，RGA **无法在精度与 Attention 持平的同时取得 ≥ 5× 实测加速**，则核心主张失败。
- **F3**：若 RGA 的硬件 benchmark 在主流 NPU 上**无法超越同精度 MobileNet**，则 H3 失败。

---

## 6. 一句话总结

> **RGA = "把 Attention 的稠密匹配换成图论的层级聚合"**。
> 我们押注的是：**结构化的对数深度**在大多数感知任务上，足以替代**稠密的二次匹配**。

## 7. 当前已知的心虚之处（Self-Audit）

| 心虚点 | 对应假设 | 计划如何补 |
|---|---|---|
| "图二次型 $zLz^\top$ 可能被等价吸收为线性双线性型" | H1 | 用 $L=I$ / 随机对称矩阵做对照消融 |
| "递归树深层信息丢失（CIFAR 已观察）" | H2 | 第一阶段·第一部分：信息流探针实验 |
| "跨子树的两个 token 必须经最低公共祖先" | H2 / L1 | 设计横向边 / shifted tree / overlapping tree 三选一 |
| "硬件友好"仅停留在直觉 | H3 | 自学 / 合作补 ASIC 或 NPU benchmark |
| "5× 加速"无定量来源 | F2 | 长序列任务的 wall-clock benchmark |
