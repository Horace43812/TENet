## 1. 实验对象与结论边界

默认机制为四顶点、六边节点，固定关联图上的 `G = diag(z) L diag(z)`，局部矩阵归一化及可学习投影。四顶点和六条边的顺序固定为代码中的光栅顺序与 `12,13,14,23,24,34`。

需要分解的对象依次是：原始顶点 → 边特征扩展 → 结构约束交互 → 归一化 → 投影 → 跨层重复。完整 TENet 的内容流、trace、cross 单独归因。

构造 `z=[v,e(v)]` 保留了全部顶点，本身没有删除顶点信息。稀疏矩阵也不能仅凭稀疏性判定信息已丢失，例如其对角线包含节点平方。重点测量投影后的任务表现及可读取性，不预设每一步都不可逆丢失。矩阵不是协方差估计，也不是直接对节点进行 `Lz` 平滑，不能直接套用过平滑解释。

## 2. 数据、随机性与最终评估

### 2.1 主数据与划分

首轮沿用现有 ImageFolder 数据，固定 train/val 共有类别按名称排序的前 50 类，输入 64×64。这是本项目指定子集，不称为标准 ImageNet-100，也不外推为 ImageNet-1K 成绩。记录数据来源、授权、原始版本、实际类别名和每类数量，不假设目录一定来自 ImageNet。

P0 对每类原始训练图片按 `split_seed=20260906` 分层划分 90% 候选训练池、10% 开发集；在候选训练池用 `data_seed=42` 固定选最多 500 张用于训练。其余训练池样本暂不使用，清单同样存档。开发集每类至少 2 张；数据太少时在训练前调整并登记划分方案，不在看结果后调整。

- train：拟合模型和探针，所有随机种子运行使用同一图片集合。
- dev：选择配置、诊断模型、等额超参数搜索。再按类别固定拆成 discovery/confirmation，用于探索性类别对复核。
- final：预留原始 val，只有确认从未被模型选择或机制分析使用时，才称为未触碰最终集。若已使用，标记“历史已查看”，另行取得同分布保留集后才能声称独立最终验证；拿不到时仍可完成探索性比较，但结论明确受限。

划分前检查路径交叉、文件内容哈希重复和可识别的同源样本；同一原图衍生版本、同主体/场景应整组划分。至少保存相对路径、标签、来源分组（如有）和 SHA-256。未来 CIFAR-100 使用原生 32×32 及单独冻结协议，不能仅改输入尺寸就与当前子集混成一张排名表。

原 `train.py` 仍使用train/val；新 `experiment.py` 已使用清单驱动的train/dev/final及独立最终评估入口。禁止在每轮训练中读取final。

### 2.2 随机性与预处理

训练种子为 42/43/44，必要时增加 45/46；它只改变初始化、训练顺序和增强。当前 `--seed` 同时影响每类抽样，必须先拆分或使用冻结清单覆盖抽样。探针种子与训练种子分开记录。

主训练预处理固定为当前 ImageFolder 的 RandomResizedCrop、水平翻转及现有 RGB 归一化常数；dev/final 和探针提取固定 Resize + CenterCrop。记录裁剪参数、插值、库版本及常数实际值，所有组一致。未来方向敏感任务需在实验前改成保留标签语义的增强。

## 3. 公共骨架与训练协议

### 3.1 机制骨架 S

`RGB → 1×1 stem(3→16) → 三个聚合阶段(16→16) → 4×4 平均池化 → Linear(256→256) → ReLU → Dropout(0.1) → 分类层`。

每阶段非重叠 2×2 聚合，空间为 `64→32→16→8`，各阶段末统一 BN/ReLU。所有阶段参数独立。机制主表使用单流，真正删除内容流、trace、cross、directed、Chebyshev、spatial；图算子内没有仅某一组保留的额外输出门控。图化先采用绝对差边，便于分解。可学习 phi 与 edge 增强是后续独立因素。

所有局部投影均允许跨通道混合。MLP 隐藏宽度预设为 32，激活 ReLU；同一组所有阶段使用相同定义。公共 stem 的第一阶段输入是学习特征，不能把“第一阶段优势”直接称为“像素纹理优势”。若出现位置优势，另做 `RGB identity stem、各阶段宽度3` 的成对敏感性实验，单独报告其容量变化。

### 3.2 优化与预算

| 项目 | 默认值/规则 |
| --- | --- |
| 优化器 | AdamW，lr=3e-4，weight_decay=0.05 |
| 学习率 | CosineAnnealingLR，T_max=100，无 warmup |
| 训练 | 100 epochs，batch=16；固定训练清单保证更新步数一致 |
| 损失 | 交叉熵，label_smoothing=0.1 |
| 模型选择 | 主分析预指定第100轮 `last.pth`；dev 最佳 checkpoint 作为次要结果 |
| 精度与设备 | 首轮 FP32；记录设备和软件版本；改变精度另列实验 |
| 比较 | 相同增强、数据、训练次数、搜索次数和评价代码 |

集成器统一处理BN的单样本末批：训练清单除以batch后余1时丢弃该末批（所有组相同），dev/final保留全部样本；实际每轮样本数随指标保存。主批次默认workers0、CPU threads4，可显式调整并记录环境。图化单流实现没有未使用的内容分支。

先检查小样本是否能拟合、梯度是否有限和损失是否正常下降。FakeData 只验流程，不能用来判别模型识别能力。

默认配方不保证对所有算子最优。若收敛诊断提示不公平，针对 G 和 Q 两个家族都提供相同的 `lr ∈ {1e-4,3e-4,1e-3}` 开发集搜索，每项一个固定种子和相同完整训练预算，选定后冻结。新增搜索计入成本，后续复核对所选配方一致执行。若延长至200轮，应从头用200轮余弦周期同时重训所有核心对照，不能只续训某一失败模型。

## 4. P0：已有证据归档与实现验收

归档记录至少包括：原命令、代码提交/补丁、数据清单、配置、各轮指标、checkpoint、探针参数、分析报告、设备。信息缺失的旧结果标记缺失项，不能补写推测值。全分支默认模型用现有实现复核，单流对照不与其混称“同模型复现”。

实现验收需覆盖：多 batch/多通道窗口顺序、各算子形状、有限梯度、观察器不改变前向、`z` 前四项等于顶点、图矩阵公式和对称性、单流无闲置分支、分类头一致、数据集合不随训练种子变化、最终集未被训练循环加载。拓扑变体另验连接数/度数/固定节点顺序。

对线性顶点投影验证其与适当权重重排后的 `Conv2d(kernel=2,stride=2)` 等价，避免将数学上相同的两个实现视为独立基线。浮点等价使用明确容差，不要求不同硬件逐位一致。

## 5. P1：图化分解矩阵

### 5.1 第一批 G1–G7

除 G7 外，均在骨架 S 的三个阶段使用同一种算子，从头独立训练。

| ID | 算子 | 局部处理 | 主要比较 |
| --- | --- | --- | --- |
| G1 / P | 均值聚合 | 每通道四点平均 → Linear(C,C) | 最简单下采样参照 |
| G2 / V | 顶点线性聚合 | 展平4C → Linear(4C,C) | 可学习空间加权；等价2×2步长2卷积 |
| G3 / Q | 顶点 MLP | 展平4C → Linear(4C,32) → ReLU → Linear(32,C) | 普通非线性局部聚合；P2固定用它作Q |
| G4 / E | 顶点＋边直投影 | 每通道四顶点＋六个绝对差 → 展平10C → Linear(10C,C) | 不构造矩阵的显式关系 |
| G5 / G | 基础图矩阵 | 相同z → diag(z)Ldiag(z) → 当前逐矩阵标准化 → 展平100C线性投影 | 固定图二阶交互 |
| G6 / G+ | 增强图矩阵 | G5增加当前 learnable-phi 和 edge 增强 | 实际可学习边机制的增量 |
| G7 / Full-S | 完整双流参照 | 宽度16、alpha0、三层；当前默认 learnable-phi/trace/edge/cross | 整体方案表现，不能单独归因于图化 |

G7 使用当前双流输出门控和融合，不要求与单流逐操作一致；单独标注其额外参数/计算。B0 另保留当前默认 RGB宽度3、alpha8 的模型，防止误把 Full-S 称为历史默认配置。

G4对G2是“绝对差特征扩展”的实用增量；G5对G4同时改变交互阶数、归一化与投影大小，不能仅凭该差异证明图拓扑有效。G5优于G1，也不足以排除普通非线性容量的解释。后续用以下对照收窄。

### 5.2 有线索后进行的关联结构对照

固定相同 `z`、单流骨架和训练协议，保留每个矩阵各自的均值/标准差计算规则。

| ID | 处理 | 能检验的内容 |
| --- | --- | --- |
| T1 | 对 `zzᵀ` 的完整100项矩阵标准化并投影 | 固定连接约束与不加该约束的二阶表示差异 |
| T2 | 保持四顶点/六边节点顺序及边特征不变，错配边节点与端点的关联 | 原有端点语义匹配是否有用 |
| T3 | `z` 直接标准化后线性投影，另加同隐藏宽度的z-MLP对照 | 归一化和普通非线性容量能否解释G5相对G4的变化 |

T2 预生成3份固定错配，保持顶点度3、边节点度2、12条连接和连通性；存储邻接矩阵及生成种子。它是“关联语义错配”而非保证不同同构类的拓扑。不能同时置换z与矩阵再宣称拓扑改变，后者可能仅是重新编号。先筛选全部错配，再对拟作结论的比较补训练种子；不能挑最差错配来衬托原结构。

T1/T2 即使矩阵尺寸相同，其非零项与统计量分布也不同。若标准化是候选主因，在中心化版本上重复相同对照；差异仍不能完全等同于抽象拓扑的因果效应。

仅将固定非零连接改成可学习常数，不列为第一优先级：在无归一化、自由线性投影的简化条件下，这些系数可以部分被后续权重吸收。数据依赖连接可作为后续架构探索，但必须给Q同等调参预算并计入成本。

### 5.3 归一化：分析与训练分开

先在同一冻结checkpoint上执行已有 A–E 分析：A=G，B=(G−μ)/s，C=sB，D=B+μ，E=sB+μ。要求E≈A通过，保持类别对按A→B在discovery选择，在confirmation复核同一批类别对。

随后在 GGG 上从头训练三种策略：标准化 `(G−μ)/s`、仅中心化 `G−μ`、无局部归一化 `G`。骨架末的BN/ReLU仍相同；标准化组复用G5，后两组为B4。若改用G+，必须预先登记并重新计预算，不能悄悄与G5混合。

只有重新训练后最终分类指标的稳定改善，才支持替代策略有效。C探针优于B只说明当前读取器受益；固定权重去归一化可能引入分布偏移，不算修复成功。D不是仅恢复原均值而保持物理量纲一致的逆变换，不用它定义训练策略。

## 6. P2：递归位置、深度与瓶颈

### 6.1 首要实验：固定三次下采样的2×2×2设计

使用骨架S，各阶段取 G5 的G或G3的Q，仍各自独立参数。G和Q的定义在查看位置结果前固定。若G+或新归一化明显更好，后续另开版本复核，不追溯替换已登记实验。

| 序列 | 含义 |
| --- | --- |
| QQQ | 无图化，来自G3 |
| GQQ / QGQ / QQG | 只在第1/2/3阶段图化 |
| GGQ / GQG / QGG | 在两个指定阶段图化 |
| GGG | 每阶段图化，来自G5 |

八组具有相同stem、输出宽度、下采样次数、最终空间尺寸和分类头。固定种子内可配对报告：GQQ−QQQ、GGQ−GQQ、GGG−GGQ，以及相同图层数量下的位置差异。报告其他背景下替换同一阶段的差值，例如 QGQ−QQQ 与 GGQ−GQQ，观察上下层选择是否影响收益。

不能只用一条增加图层的顺序判定递归。不同位置的算子运算量不同；结果必须附参数/运算表，并对保留候选做资源匹配。若G仅适合第一阶段，后续需检查stem、归一化及更大预算，才讨论输入特征适配。

### 6.2 深度趋势：诊断性补充

在64×64输入下比较纯G与纯Q的L=1/2/3/4，恒定C=16、alpha0、head-grid4；最终边长分别32/16/8/4，分类头输入和参数相同。L3复用已有配置，共新增6配置，每个先一个种子。

记录端到端精度、训练/开发loss、各层输入/输出探针和预算。深度变化同时改变下采样总量、覆盖范围和参数量，所以此表仅描述整体趋势；配合6.1和6.3判断原因。禁止对L5继续用head-grid4，也不通过更大分类头替浅层增加优势。

### 6.3 一次只验证一个瓶颈家族

| 候选解释 | 成对改动 | 控制与解释边界 |
| --- | --- | --- |
| 幅值处理不合适 | GGG三种归一化策略 | 先完成5.3，不能与加宽同时修改 |
| 通道容量不足 | GGG和QQQ都将恒定宽度16改为32 | 相同头结构但输入参数变化，记录头/骨干成本；收益可能是一般容量效应 |
| 直接内容路径有用 | GGG和QQQ每阶段都增加 `meanpool→1×1` 加法路径，放在末端BN/ReLU前 | 两者同样增加路径；不是只给G补偿 |
| 下采样太早 | 下述六块骨架两种安排 | 相同三次下采样、三次同分辨率处理及同一最终头 |

下采样安排使用独立配对家族：D为G或Q的2×2步长2聚合；P为共同的C→C的3×3步长1卷积+BN/ReLU。固定C=16，比较 `DDDPPP` 与 `DPDPDP`，分别对G和Q训练，共4配置。两种安排的P作用分辨率、理论感受野和运算量会变化；它测试下采样安排的实用效果，不是只改变一个纯粹“信息损失量”。P引入跨窗口交互，不能将收益全部记作递归图本身。

修复若有效，固定修复后至少重做 QQQ/GQQ/GGG 成对比较。只运行一组多个改动叠加的最佳模型，不足以形成瓶颈归因。

## 7. 真实类别与层内探针

先比较真实分类结果，再沿 `input→vertices→nodes→graph_raw→graph_normalized→projected→output` 定位变化。普通算子增加相应input/output及中间表示观察接口，不强行伪造不存在的graph阶段。

主探针固定grid4、dim256、线性读取器、probe_seed123；探针只在train拟合标准化和权重，固定训练轮数，不按dev挑最佳轮次。采样整张图的标签，不给每个窗口强加图像类别。

对核心疑点复核：dim512、probe_seed124/125、hidden64；grid敏感性使用2和4，只有所有被比较表示的边长均≥8时才加grid8。由于哈希在不同原始维数上产生的映射不同，“同维探针”不保证测量失真相同。`input→vertices`可逆重排作为测量参照；若它就出现大幅差异，优先调查描述符。

预设选discovery上退化最大的前10个真实类别对，按已有双向误判增量规则排序，在confirmation报告同一列表、样本数及变化；同时保留全部类别对和全部lost/recovered图片。类别对差异用于形成假设，不能根据样本视觉印象认定网络只会识别纹理。图像梯度只表示局部敏感性。

CKA、有效秩等若补充实现，只作描述统计。任何probe下降都不能直接换算“任务信息保留率”，也不能证明完整模型不可恢复该信息。

## 8. 预算匹配与统计规则

### 8.1 预算比较

先报告骨架S的原始参数、骨干/头分项和运算量；图投影中重复、对称及归一化后特殊坐标不等于独立自由度，不将100个矩阵位置都称为100个独立特征。

资源对照使用预登记候选：恒定C∈{8,16,24,32}，Q的隐藏宽度∈{16,32,64,128}。先只构造模型和统计成本，再按离目标预算最近选配置，不用dev精度挑匹配对象。所有组仍使用相同形式的head-grid4/head-hidden256；总参数匹配必须包括头，另报头占比。主资源目标取G在C=8/16/32的三个预算点，机制表的Q(C16,H32)不因此改名。

- 参数匹配容差±5%；运算量匹配容差±10%，分别进行。
- 无候选落入容差就标记“未匹配”，报告邻近预算点，不加无用参数、不虚构插值精度。
- 不以稀疏理论项数代替当前稠密实现的实际计算；MACs与FLOPs标明约定（若换算则1 MAC=2 FLOPs）。
- 统计未覆盖的phi、标准差、逐元素算子等明确列出；工具不支持时报告“未完整计量”。

### 8.2 主指标、差异与不确定性

主指标为预指定最后一轮的Top-1。次指标为dev最佳checkpoint、逐类平均召回、完整混淆矩阵、普通未平滑交叉熵NLL、训练稳定性及成本。当前训练loss带label smoothing，不能直接标为NLL。

每个完整配置至少3个训练种子后才作复核结论，报告各次值、均值、样本标准差。成对模型使用相同训练种子并报告差值Δ；相同种子不意味着不同结构获得完全相同初始化或增强随机轨迹。

对成对差值报告95% t区间 `mean(Δ) ± t(0.975,n−1)·sd(Δ)/sqrt(n)`。3种子区间通常很宽，按训练随机性的粗略不确定性描述，不当作全面的数据总体保证。若另做样本bootstrap，按类/来源分组配对重采样，并将样本不确定性与种子不确定性分开报告。

预设研究决策规则：均值改善≥0.5个百分点且配对95%区间下界>0，才记作本轮“支持改善”；否则按区间记为线索或无法区分，不把未显著当等价。大量类别对和配置筛选均标为探索性；冻结后在最终集只检验预登记的核心比较，避免事后挑最优差值。

效率候选门槛：精度差值区间下界不低于−0.5个百分点，同时目标设备延迟或峰值内存至少改善10%。这是本轮决策门槛，需同时报告原始结果和测量波动，不泛化为任意硬件优势。

## 9. P3：优势范围与实测效率

只保留普通聚合参照、最佳可解释图候选和必要的完整TENet参照，按以下顺序扩展：

1. 相同数据的三个预算点，检查优势是否依赖极窄通道。
2. 固定相同样本的64/128分辨率对照，单独记录预处理与成本，不把分辨率收益归为算子收益。
3. 第二个预先冻结的类别子集（如排序第50–99类，数据足够时），检查类别选择偏差。
4. CIFAR-100或另一个真实分类数据集，作为独立任务复核；所需加载器与train/dev/final划分先实现。

若真实类别对提示局部材质/颜色/布局差异，在看新结果前形成具体假设，再选择对应数据或干预。可对同一固定评估图片做灰度化、轻度模糊、网格打乱和小幅平移，预存相同变换列表并对所有候选评估。这些是分布外敏感性诊断，尤其打乱可能改变标签语义，不能当作新的标准分类准确率或纹理偏好证明。医学、遥感、点云适配不纳入首轮任务。

硬件测量针对实际候选：eval + inference_mode，batch1测延迟、batch16测吞吐；固定输入尺寸、dtype和设备。设备内预生成输入，不计磁盘加载与预处理；主表包含模型中的窗口重排、矩阵构造和所有分支。

每次先预热50次，再测200次，独立重复5批。GPU计时使用CUDA events或计时边界显式同步；CPU固定线程数并用单调高精度时钟。报告每批统计、中位数、P90和跨批波动，不只报最快值。GPU重置峰值统计后报告allocated/reserved及推理/训练内存分别测量；CPU的进程RSS另列，不能与GPU allocated直接混比。

记录GPU/CPU型号、显存、操作系统、PyTorch/CUDA/cuDNN版本、线程、编译模式、batch与dtype。主表为当前eager实现；编译、稀疏/融合内核或量化另开同条件对照。没有目标MCU测试就不声称MCU优势。

## 11. 归档、停止条件与报告模板

每次运行使用唯一experiment_id、seed和run_id。大权重保留在runs或实验存储，文档只存索引，不提交数据图片和完整权重。

```text
docs/90_results/graphification_recursion/<batch_id>/
  report.md                 # 假设、配置差异、全部结果、解释边界
  runs.csv                  # run_id、seed、commit/patch、配置、checkpoint及哈希
  comparison.csv            # 每次结果、均值/标准差、配对差值与区间
  cost.csv                  # 参数分项、运算口径、延迟、吞吐、内存
  decision.md               # 保留/停止的原因及下一阶段冻结比较
  manifests/                # 相对路径、标签、划分和内容哈希；不含图片
```

以上为未来目录规范，本次不创建空结果或虚构成绩。每份报告使用以下结构：

1. 假设及实验前预设的主要比较。
2. 数据/代码版本、训练种子、完整配置和实际差异。
3. 全部运行结果，包括OOM、NaN、失败和重跑原因。
4. 效应大小、不确定性、资源差距和完整类别对列表。
5. 哪些解释得到支持，哪些仍被其他因素混淆。
6. 下一步及停止条件；偏离协议的地方、发生时间和原因。

出现数据泄漏、窗口错误、E/A恢复失败或错误checkpoint立即停止相关结论，修复后重跑受影响组。OOM计为该设备条件下不可行；若减batch，配对模型同步调整并另记配置。训练不收敛进入共同训练诊断，不直接宣告某算子无效。

若图化在充分训练、三个种子和预算对照后均未获支持，停止扩大当前配置，保留“测试范围内无稳定优势”的结果。若只有局部位置获益，先完成该条件的复核再转模块研究。最终结果允许否定当前设计，不能用未执行的理想优化替代证据。
