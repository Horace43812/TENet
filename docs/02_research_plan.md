## 2. 第一阶段：机理探究

### 总目标
回答三个问题：
1. **TENet 各层实际捕获了哪些信息？**
2. **哪些信息在何处丢失？为什么？**
3. **基于上述发现，应该如何改进结构？**

最终产出 **RGA v1.0 工作版理论**：一套对自己的机制有清晰认知、能在多数据集上稳定工作的方法。

---

### 1.1 信息流探针实验（**当前焦点**）

**目标**：用可量化的指标刻画 TENet 每一层"输入了什么、输出了什么、丢了什么"。

**方法工具集**（详见 [10_phase1_mechanism/01_information_flow_probe.md](10_phase1_mechanism/01_information_flow_probe.md)）：
- 工具 1：**有效秩（Effective Rank）** —— 测带宽
- 工具 2：**Linear CKA** —— 测层间信息保留
- 工具 3：**输入梯度归因** —— 测跨子树泄漏
- 工具 4：**层级 Linear Probe** —— 测任务相关信息保留
- 工具 5：**$\phi$ 函数形状可视化** —— 测算子学到了什么

**关键实验对照**：
- 不同数据集：MNIST（已通过） vs CIFAR-10（撞瓶颈） vs CIFAR-100（待测）
- 不同 `alpha`：1, 4, 8, 16, 32
- 不同深度：2, 3, 4, 5 层
- 不同模块开关：trace_branch / edge_enhance / cross_guidance 等

**交付物**：
- 信息流曲线集（每个实验配置一组曲线）
- 一份 [10_phase1_mechanism/02_findings.md](10_phase1_mechanism/02_findings.md)（待建）总结发现

### 1.2 失效模式定位与归因

**目标**：基于 1.1 的数据，确定 TENet 在 CIFAR / 更深层场景下的**主导失败模式**。

**候选失败模式**（先验假设，待证伪）：
- 模式 A：**带宽瓶颈**（每层 4:1 空间压缩 vs $(C+\alpha)/C$ 通道扩张）
- 模式 B：**$L$ 的低通性导致 over-smoothing**
- 模式 C：**树结构跨子树切断中尺度结构**
- 模式 D：**通道独立 → RGB 颜色耦合丢失**

**输出**：[10_phase1_mechanism/03_failure_modes.md](10_phase1_mechanism/03_failure_modes.md)（待建），明确指认主导失败模式 + 证据。

---

### 1.3 扬长补短：结构改进与验证

**目标**：基于 1.2 的归因，**针对性**地设计 3~5 个改进实验，每个改进对应一个失败模式。

**改进候选池**（按失败模式分类）：

| 失败模式 | 候选改进 |
|---|---|
| A 带宽瓶颈 | 提高 alpha；引入残差跳连；多尺度输出 |
| B over-smoothing | $L$ 加入自环；改用归一化 Laplacian；引入边的非线性激活 |
| C 跨子树切断 | 横向边（同层 4-邻接）；shifted tree；overlapping tree（stride=1） |
| D 通道独立 | $\phi$ 前加 1×1 跨通道混合；引入通道图 |

**评估准则**：
- **正向**：CIFAR-10 上精度 / linear probe 曲线提升
- **代价**：新增参数 / FLOPs
- **理论一致性**：是否破坏 H1 / H2 / H3 的核心承诺

**输出**：[10_phase1_mechanism/04_remedies.md](10_phase1_mechanism/04_remedies.md)（待建）

## 3. 第二阶段：应用探索（双轨制）

### 2.A 独立路线：RGA 作为新视觉范式

**目标**：在标准视觉基准上，与 Transformer 及主流 CNN 在**精度 / 参数 / FLOPs / wall-clock** 多维度对比。

**关键实验**：
- CIFAR-10/100：参数等量级 vs DeiT-Tiny / ResNet-18
- ImageNet-100 或 ImageNet-1K（资源允许）
- 长序列任务（视频分类 / 长文本）以体现 $O(N)$ 优势

**关键技术挑战**：
- 第一阶段未解决的 H2 缺陷（如仍存在）需要绕开或解决
- 训练 recipe（warmup / schedule / regularization）的工程优化

---

### 2.B 嵌入路线：图化层作为 Transformer 改进元件

#### 2.B.1 作为 Patch Embedding 替换
- 把 ViT 的 Conv-based patch embedding 换成 GraphifiedLayer
- 评估：CIFAR / ImageNet 上精度变化 + 参数变化

#### 2.B.2 作为可解释 Token 剪枝准则
- 用图二次型 $zLz^\top$ 的 **trace 能量** 作为 token 重要性度量
- 在大模型推理时按 trace 排序剪枝低能量 token
- 评估：剪枝率 / 精度损失 / 推理加速

**潜在亮点**：**可解释的、结构化的 token 剪枝**是当前大模型推理优化的强需求且无公认方案。
